# ClarityPath AI

We are building a premium AI-powered Debt Advice Platform for customers only.

 

I have attached a few reference images for inspiration. Please review them carefully to understand the overall visual style, spacing, layout, and user experience. Do NOT copy any design, components, or layouts directly. Use them only as inspiration to create a unique, modern, premium, and enterprise-quality interface.

 

Also, in the Hero section, leave a dedicated space on the right side for a promotional/demo video that will be added later. Do not place an image there; simply design the layout with an appropriate video placeholder.

 

This is NOT a landing page for marketing. It is the customer-facing website/application where users can create an account, start their debt assessment, manage their cases, and interact with the AI platform.

 

Design the entire customer website with a clean, trustworthy, modern, and highly professional SaaS experience. The UI should feel premium, interactive, and suitable for a legal + financial + AI platform.

 

Use your own judgment for:

- Color palette

- Typography

- Layout

- Components

- Icons

- Spacing

- Animations

- UI patterns

 

Do not use generic templates. Create a custom enterprise-level experience.
